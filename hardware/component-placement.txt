GC-20 v2 Component Placement Coordinates
==========================================
Last updated: 2026-03-07 (v2.1 - confirmed on-board placements)

BOARD OUTLINE
--------------
Size: 2560 x 4250 mils (65mm x 108mm, matches SBM-20 tube length)
X range: -1280 to +1280
Y range: -1500 (bottom) to +2750 (top)

EasyEDA board outline rectangle:
  Origin: (-1280, 2750), Width: 2560, Height: 4250

LAYOUT ZONES
--------------
Display area:      Y = -650 to +2450 (J6 to J5, Adafruit 2090 on top)
Under-display:     Y = -500 to +2300 (usable SMD area, ~6mm clearance)
Below-display:     Y = -700 to -1500 (tall components + edge connectors)

Under-display clearance: ~6-8mm (set by standoff height).
Any component < 4mm tall fits safely. All 1206, SOT-23, SOIC-8,
SOT-89, QFN, and WS2812 parts fit. Only buzzer, toggle switch,
3mm LED, and tactile buttons are too tall.

NOTES
======================================================================
- All rotations default 0. Rotate passives 90deg as needed for routing.
- R14 (trimmer) in below-display strip for adjustment access.
- HV section MUST have ground pour gap isolating it from digital.
- GM tube wires connect to pads on right board edge (add to schematic).
- Vibrate motor wires connect to pads (add to schematic).
- Under-display components are on TOP copper, facing up toward display.
- ~6mm clearance under display set by standoff height at mounting holes.
- Board outline change: height 5500 -> 4250 mils (top stays at Y=+2750).
